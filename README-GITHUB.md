# Entomologia Agraria — App PWA

Caricare nella root della repository tutti i file e le cartelle contenuti in questo pacchetto mantenendo la struttura.

File principale: `index.html`

Per GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.

La PWA funziona offline dopo la prima apertura via HTTPS.
